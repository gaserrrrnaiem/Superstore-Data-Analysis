# Superstore Sales Data Analysis 📊

## 📌 Project Overview
This project is a mini-project focused on analyzing retail sales data from the Sample Superstore dataset. The goal is to extract valuable business insights, identify key performance indicators (KPIs), and present strategic recommendations.

## 🛠️ Tools & Libraries Used
* **Python** 
* **Pandas & NumPy** (Data manipulation & cleaning)
* **Matplotlib & Seaborn** (Data visualization)

## 📁 Files in this Repository
* `Superstore_Analysis.ipynb`: The main Jupyter Notebook containing the full code, data cleaning steps, and analysis answers.
* `Sample-Superstore2019.csv`: The dataset used for the analysis.

## 🚀 Key Insights
* Identified top-performing product categories and sub-categories.
* Analyzed regional profitability and shipping patterns.
* Provided data-driven business recommendations.
